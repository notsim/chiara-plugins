# Plugin curati

Questa cartella contiene i plugin **approvati** che girano in produzione sul bot Chiara.

Ogni plugin è una cartella con un `plugin.json`. L'aggiunta avviene solo tramite **Pull Request approvata** (review manuale).

## Come proporre un plugin

1. Crea la cartella in `examples/` (o direttamente qui se è già stato concordato).
2. Valida con `npm run validate`.
3. Apri una PR spiegando cosa fa il plugin e un esempio di conversazione.
